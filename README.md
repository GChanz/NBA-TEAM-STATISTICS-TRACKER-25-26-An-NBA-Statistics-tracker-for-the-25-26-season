NBA-TEAM-STATISTICS-TRACKER-25-26
An NBA Statistics tracker for the 25/26 season

This project uses a python backend to call statistical information from the public NBA_API and serve it to a html frontend via javascript. It also functions as a stat comparer to measure how up to 5 NBA team compare to each other over a range of categories. This data can be used to infer the defensive and offensive capabilities of each team in the 2025-2026 NBA season.

This project is be run via a VS code live server to show full functionality.
